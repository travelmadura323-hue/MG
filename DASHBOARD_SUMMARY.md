## 🎓 Learning Resources

### To Customize Colors
1. Open target component file
2. Find Tailwind color classes (e.g., `bg-blue-600`)
3. Replace with your colors
4. Test immediately in browser

### To Add Fields
1. Extend `Tour` interface in `lib/data.ts`
2. Add form input in component
3. Update hook if needed
4. Test form submission

### To Modify Layout
1. Find component file
2. Change Tailwind classes
3. Adjust spacing/sizing
4. Test responsiveness
